# Carlos Sonic-Inspired One Pager

Landing one-page en React + Tailwind + Framer Motion con una direccion visual inspirada en velocidad y energia.

## Comandos
- npm install
- npm run dev
- npm run build
- npm run preview

## Personalizacion rapida
- Nombre, links y correo: src/App.jsx
- Colores y tipografias: tailwind.config.js
- SEO base: index.html

## Deploy recomendado
- Vercel (framework: Vite)
- Netlify (build: npm run build, publish: dist)
